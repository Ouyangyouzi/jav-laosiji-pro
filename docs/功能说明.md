# JAV老司机 · 魔改 pro · 功能说明

**版本 v3.0.3.3** ｜ 基于 ZiPenOk《JAV老司机-新》魔改 ｜ 适配 Tampermonkey / Violentmonkey

> 一句话概括：把「找片 → 下磁力 → 推 115 → 自动归档 → 播放 / 追新」这条链路，压缩在一个脚本、几个按钮里。
> 不用来回复制番号，不用手动在 115 里翻文件夹，也不用为了看一部片开五个标签页。

---

## 一、这个脚本的特点

| 特点 | 具体表现 |
| --- | --- |
| **全链路打通** | 详情页识别番号后，磁力聚合、115 离线、按模板归档、在线播放、NAS 定位都在同一页完成，不跳站、不重输番号 |
| **115 深度整合** | 文件列表直接匹配作品并显示封面与资料；离线推送可先选演员文件夹；下载完自动清理垃圾文件、规范改名、按模板归位 |
| **手动离线零门槛** | 点「📥 115手动离线」就弹出推送窗口，顶部粘贴 magnet / ed2k 链接，点一下「识别磁链」即得番号、演员与候选文件夹，未识别前列表自动置灰防误点 |
| **演员文件夹自动归档** | 按番号查演员 → 在 115 里匹配同名文件夹 → 按优先级推送；支持别名、模糊匹配与「弱匹配」提示，避免把片塞错人 |
| **防误命中** | 单字演员名、前缀包含这类容易误判的情况有专门守卫（如「葵」不会命中「葵百合香」），宁可不出候选，也不乱推 |
| **NAS 四家通吃** | Emby / Jellyfin / 飞牛 / WebDAV 可同时开启，命中即出「XX匹配」按钮，Emby 系网页直接播，WebDAV 出文件直链 |
| **界面高度可调** | 卡片列数、竖图模式、页面缩放、悬浮大图、瀑布流、快捷操作都能单独开关，桌面与移动端各有独立参数 |
| **数据在本地** | 作品库、黑名单、缓存全部存本机；可分类清理缓存，可导出 / 导入 JSON 备份，导入前自动留快照 |
| **一个人也能维护** | 设置分 8 个分页，改完即时生效；每一项都有中文说明，不写配置文件 |

## 二、功能说明

### 1. 番号识别与详情页增强

- **多站识别**：主流资料站及其常用镜像域名，自动从标题与页面结构提取番号（含 FC2、无码、VR 等格式）。
- **演员与短评**：详情页展开演员资料、收藏演员高亮、短评列表默认展开与字号调节。
- **封面**：支持下载高清封面与竖版封面（最高 2K），可切换无水印封面源。
- **标题翻译**：可选关闭 / 仅列表 / 仅详情 / 全部，翻译结果缓存，不重复请求。
- **详情页布局**：封面与信息区比例可调，预览图可直接在详情页展开，无需点开弹窗。

识别成功后，详情页按钮栏会补齐十余个入口，每个都能在设置里单独关闭：

| 分类 | 入口 |
| --- | --- |
| 磁力 | 聚合搜索、单站搜索、复制磁链、下载种子 |
| 资料库 | 作品资料、FC2 专项、厂牌与系列资料 |
| 观看 | 在线观看、正片、预告片、预览图 |
| 115 | 115 匹配、115 手动离线 |

### 2. 磁力聚合与搜索

- **三种显示方式**：独立磁力表、原页面增强、关闭。原页面增强时可选默认标签（原站磁力 / 聚合结果）。
- **聚合引擎**：内置多家磁力来源，可单站或聚合搜索，域名可在设置里替换。
- **排序与筛选**：按大小 / 最新 / 最旧 / 来源数排序；筛选全部、多文件、单文件；可指定只显示哪些来源。
- **快捷操作**：列表卡片上的快捷菜单支持复制番号、下载高清封面 / 竖版封面 / 预告片，一键跳到搜索或资源管理。

### 3. 115 匹配与播放

- **列表匹配**：在 115 文件列表按番号自动匹配，命中后在文件行显示徽标与封面。
- **播放方式**：官方播放器 / 115Master / PotPlayer，按习惯选。
- **信息卡片**：四档显示——关闭、仅封面、封面 + 信息、封面 + 信息 + 剧照；可只作用于文件、只作用于文件夹，或两者都显示。
- **演员文件夹头像**：115 里的演员文件夹内显示圆形头像，找片更直观。
- **候选排序**：同名多文件时，疑似预告 / 样片（文件名带 tp、trailer、sample、preview 等）与体积过小的会降权，同条件下体积大的优先，减少选错版本。
- **字幕直传**：搜索到字幕后可直接传到 115 对应目录，命中已有文件时走秒传，省流量；未匹配到作品目录时可指定一个默认字幕目录。
- **文件操作**：「老司机移动 / 复制 / 删除」在 115 新版界面上可用，移动后会校验源目录，避免「显示移走了其实还在」的假成功。

### 4. 115 手动离线（本版新增）

详情页点「📥 115手动离线」，直接弹出「推送到哪个文件夹」窗口，三步走：

1. **粘贴链接**：窗口顶部是多行输入框（两行高，可上下拖拽放大），支持一次粘一条，也支持一行粘多条。
2. **点「识别磁链」**：自动解析链接类型、提取番号、查演员资料，并在 115 里匹配同名演员文件夹。
3. **选位置**：识别成功后列表解锁，按优先级列出「演员匹配文件夹 / 手动选择文件夹 / 默认云下载文件夹 / 指定文件夹」，点哪个推哪个。

| 支持的链接 | 说明 |
| --- | --- |
| `magnet:?xt=urn:btih:…` | 标准磁力，大小写不敏感 |
| `ed2k://\|file\|…\|/` | 电驴链接，自动从文件名提取番号，hash 统一大写，支持 `h=` AICH 参数 |
| 40 位十六进制 | 裸 btih，自动补成完整磁力 |
| 32 位 Base32 | 裸 btih，自动转码补全 |

细节：

- 未识别时下方文件夹列表整体置灰、不可点，避免「没识别就推错目录」。
- 识别成功会更新副标题为「番号 · 演员：A / B / C」，并提示识别到几个演员文件夹。
- `Enter` 直接识别，`Shift + Enter` 换行；链接里带尖括号、引号会自动清理。
- 识别不到演员时仍可走「手动选择文件夹」或「默认云下载文件夹」，不会卡死流程。

### 5. 115 离线整理（按模板归档）

推送前可先套模板，下载完再自动清理与改名：

| 层级 | 模板 | 支持的变量 |
| --- | --- | --- |
| 离线目录 | 默认 `云下载/${actors}` | `${code}` `${actor}` `${maker}` `${series}` 等 |
| 文件夹名 | 默认 `${code}${suffix}` | `${code}` `${suffix}` `${title}` |
| 文件名 | 默认 `${code}${suffix}` | `${code}` `${suffix}` `${crack}` `${ltx}` `${res}` |

- **垃圾清理**：无字幕且小于阈值（默认 150 MB）的视频判为过小；无番号、非视频、无番号图片、广告图、广告关键词文件、垃圾目录一并清掉，每条判定都有原因可查。
- **自动清理并改名**：可关，关掉后在整理面板手动点「一键清理 / 一键规范改名」。
- **整理面板四个动作**：按模板整理、一键清理、一键规范改名、改名后移动到指定目录（支持变量，也可点「选择…」直接从 115 里挑目录）。
- **整理顺序可调**：原目录 / 番号文件夹 / 平铺（不建番号文件夹）/ 演员文件夹 / 自定义，用 ▲▼ 调整，面板下拉按此顺序显示；当前项不可用时自动回退下一项。
- **不建番号文件夹**：开启后文件平铺进演员文件夹，文件夹搬空后自动删除；关闭则保留「ACHJ-100-C」这类番号子文件夹。

### 6. 演员文件夹匹配

- 开启后，点「115离线 / 推送整理到115」会先匹配 115 里的演员文件夹，选好目标再推送；关闭则恢复直接推送。
- **根目录**：只在指定层级下找演员文件夹（如 `云下载` 或 `云下载/演员`），留空表示从 115 根目录找。
- **候选上限**：默认 6 个，避免一次列出几十个同名文件夹。
- **别名表**：每行一条 `日文名=别名1,别名2`，把中文文件夹名映射到日文演员名。
- **自动用最高优先级**：开启后不弹菜单，直接推到优先级最高且可用的项（跳过手动选择）。
- **弱匹配提示**：只按前缀 / 包含命中时会标注「弱」，自动模式不会选弱匹配，防止错推。

### 7. 预告片、正片与预览图

- **预告片**：多画质可选，最高 4K；关闭高清时最高 720P，省流量。解析失败可走中转播放。
- **正片**：详情区封面可直接加载完整播放器，支持按版本优先（有码 / 无码 / 中字），没有则回落普通版本。
- **预览图**：三路来源，顺序可用左右按钮调整，命中即显示，不阻塞页面。
- **悬浮预览**：鼠标停在封面出高清大图；115 里的封面同样支持悬浮预览。

### 8. 列表页与界面

- **卡片列数**：普通卡片与竖图卡片分开设置，桌面 2–10 列；移动端横屏、竖屏各自独立。
- **竖图模式**：改用更适合封面的纵向卡片。
- **页面缩放**：60%–100%，按站分别设置，宽屏下不再拉成一条。
- **动效**：卡片上浮动画、封面缩放；可关。
- **瀑布流**：滚动到底自动加载，刷新或返回时恢复已加载内容。
- **其他**：列表链接新标签打开、列表默认按发布日期排序、详情页默认显示磁力还是短评、短评字号。

### 9. 跨站搜索与跳转

- **首选站可配**：三大站、磁力搜索、资料库、FC2 资料库、搜索引擎、在线观看，六类各选一个默认。
- **一处跳转**：详情页与 115 菜单都能直接跳去搜索，找不到资源时不用回详情页重新来一遍。

### 10. NAS 匹配

识别到番号后向 NAS 媒体库查询同名影片，命中即显示「Emby匹配 / Jellyfin匹配 / 飞牛匹配 / WebDAV匹配」按钮：

| 媒体库 | 连接方式 | 命中后 |
| --- | --- | --- |
| Emby | API Key 或用户名密码 | 网页直接播放 |
| Jellyfin | API Key 或用户名密码 | 网页直接播放 |
| 飞牛影视 | API Key 或用户名密码 | 网页直接播放 |
| WebDAV | 地址 + Basic 认证（可匿名） | 打开文件直链，候选列表可复制链接 |

- 四家可同时开启，互不影响。
- WebDAV 支持指定起始子路径与扫描深度（1–6 层，建议 2–3），目录索引本地缓存。
- 检测有明确的成功 / 失败提示，失败时会说明原因，不会静默无反应。

### 11. JAV 智能演员（作品库）

把看过的片登记成自己的作品库，并自动追新：

- **作品库**：按已收藏 / 已下载 / 已观看 / LTX破解 分类查看，支持批量标记本页作品。
- **鉴定记录**：每次鉴定与检测结果都留档，可回查某部片是什么时候、按什么规则判定的。
- **屏蔽列表**：作品黑名单，另支持番号关键词（如 `SIVR`、`DSOD`）与标题关键词，命中后从作品库和记录里隐藏。
- **演员黑名单**：不想再看到的演员加进去，作品不再入库。
- **检测设置**：增量检测（遇到已知作品即停）/ 全量校验；并发 1–8；请求间隔 0–5000 ms。并发过高可能触发 Cloudflare 验证，建议保守。
- **定时任务**：自动同步收藏演员、自动检测演员最新作品，可分别设置间隔；关页面即停，重开后按保存的下次执行时间补跑。
- **备份与恢复**：导出 JSON、导入（先预览再合并，不静默覆盖）、最近一次导入前快照可一键恢复。

### 12. 设置与缓存

- 设置分 8 页：常用、界面相关、搜索与播放、站点与按钮、115 相关设置、演员匹配、NAS 匹配、缓存与高级。
- 改动即时生效，不需要刷新页面。
- 缓存按 6 类清理：预览图与封面、预告片与播放进度、115 匹配、115 信息卡片、页面数据、演员信息；也可一键全清。清理缓存不影响设置与作品库。

## 三、上手建议

1. 先到「设置 → 常用」把详情页按钮按需关掉一批，按钮栏会清爽很多。
2. 用 115 的话，先配「演员文件夹根目录」，再开「演员文件夹匹配」，之后离线推送就能选人归档。
3. 常下磁力但番号不全的，把「115手动离线」当主入口：粘链接 → 识别 → 选目录，三步结束。
4. 有 NAS 的，把媒体库账号（API Key 或账号密码）配上，详情页会多出「匹配」按钮，点开就是本地已下好的那份。
5. 追新需求多的，开「智能演员」的定时检测，增量模式即可，别把并发开高。
