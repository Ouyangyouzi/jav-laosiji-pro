# JAV老司机 · 魔改 pro

把「找片 → 下磁力 → 推 115 → 自动归档 → 播放 / 追新」这条链路，压进一个油猴脚本、几个按钮里。不用来回复制番号，不用在 115 里一层层翻文件夹，也不用为了看一部片开五个标签页。

## 安装

1. 先装脚本管理器：[Tampermonkey](https://www.tampermonkey.net/) 或 Violentmonkey。
2. 点这里安装：[**jav-laosiji-pro.user.js**](https://raw.githubusercontent.com/Ouyangyouzi/jav-laosiji-pro/main/jav-laosiji-pro.user.js)，在管理器的安装页点「安装」。
3. 打开任意支持的页面，右下角会出现可拖动的 ⚙，点开就是设置面板，共 8 个分页。

想先看效果再装，可以直接读源码：[`jav-laosiji-pro.user.js`](jav-laosiji-pro.user.js)。

### 首次配置的建议顺序

1. **设置 → 常用**：把详情页按钮按需关掉一批，按钮栏会清爽很多。
2. **115 相关设置**：先填「演员文件夹根目录」，再开「演员文件夹匹配」，之后离线推送就能选人归档。
3. **NAS 匹配**：有自建媒体库的，把地址和凭据填上，详情页会多出「XX匹配」按钮，点开就是本地已下好的那份。
4. 常下磁力但番号不全的，把「📥 115手动离线」当主入口：粘链接 → 识别 → 选目录，三步结束。

## 魔改了什么

相对原版，这个版本改的是「链路里的断点」，不是重写。原版功能一个没删。

| 改动 | 说明 |
| --- | --- |
| **115 手动离线（新增）** | 详情页点一下直接弹出「推送到哪个文件夹」窗口，顶部是多行输入框，粘贴 magnet / ed2k / 裸 hash 后点「识别磁链」，自动解番号、查演员、匹配 115 里的演员文件夹；未识别前列表整体置灰，防错推 |
| **ed2k 识别** | 原版只认 magnet 与裸 btih，电驴链接判为无效。本版新增 ed2k 解析：hash 统一大写、支持 `h=` AICH 参数、从文件名提番号、尖括号与引号自动清理 |
| **整理链路容错** | 平铺模式（不建番号文件夹）全链路透传、目标路径容错、资料缺失时明确提示而不是静默失败 |
| **NAS 匹配增强** | 命中结果缓存与详情挂载更稳，四家（两套 Emby 系 + 飞牛 + WebDAV）可同时开 |
| **演员文件夹头像** | 115 里的演员文件夹内显示圆形头像，找片更直观 |
| **播放探测守卫** | 探测超时放宽到 4s，加 `loadingAt` 重试守卫，弱网下不再误判「没有播放源」 |
| **身份与入口** | 更名 `JAV老司机 · 魔改 pro`、独立版本号、反馈入口指向本仓库 |

### 与原版的关系

- 代码基线：上游 `3.0.0.2`，魔改在本地逐版累积；本版（`3.0.3.4`）即该基线的完整魔改形态。
- 版本号四段式 `3.0.3.4` = 对标的上游版本 `3.0.3` + 本地修订序号 `4`。**第 4 段只表示发布顺序，不代表功能已与上游逐项对齐。**
- **尚未并入**：上游 `3.0.3` 的两处改动 —— ① 6 项移动端样式（设置面板导航横滑 / 详情页按钮组换行 / 资源中心头部 / 工具栏 / 演员卡片与分页紧凑化 / 115 剧照栅格）与悬浮齿轮淡出；② 115 信息卡片缓存清理后的计数归一（原来无论清了多少都显示「已清理 1 项」）。两者已在开发分支完成验证，将在下一版合入。
- **已知差异**：上游 3.0.3 新增的「FC2 官方来源」模块（用于 115 信息卡片的封面 / 信息 / 剧照）尚未移植，FC2 作品的信息卡仍走第三方来源。上游那份是整份重压缩的产物，内部标识符全部换名，文本级合并会直接产生 `Identifier has already been declared`，需要按模块重写。合并过程与冲突明细见 [`docs/上游3.0.3合并说明.md`](docs/上游3.0.3合并说明.md)。

## 数据与隐私

- 所有数据（作品库、黑名单、缓存、设置）都存在**本机**脚本存储里，不上传任何服务器。

## 发布流程（维护者）

发版只改仓库里的 `jav-laosiji-pro.user.js`，Greasyfork 那边不用手动上传：

1. 改脚本并把 `@version` 与脚本内常量 `li` 同步递增（四段式，如 `3.0.3.5`）。
2. `git commit && git push` 到 `main`。
3. GitHub 上的 `Sync to Greasyfork` 工作流会立刻请求 Greasyfork 去 `raw.githubusercontent.com/.../main/jav-laosiji-pro.user.js` 拉新版本；即使这一步失败也没关系，Greasyfork 的「自动」同步本身会定期检查该地址。

Greasyfork 侧的一次性配置（在脚本「管理 → 源代码同步」里）：同步地址填上面的 raw 链接，方式选「自动」。
